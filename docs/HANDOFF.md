# 인수인계 (Claude Code · GitHub Copilot 공용)

이 문서는 **지금 상태와 아직 확인되지 않은 일**만 적습니다. 기능의 설계 이유는 `docs/DESIGN.md`, 버전별 한 줄 이력은 `docs/CHANGELOG.md`, 작업 규칙은 `AGENTS.md`에 있습니다. 작업을 이어받으면 이 문서와 `AGENTS.md`를 먼저 읽으세요.

마지막 갱신: 2026-11-02 (한국 시간), 버전 0.5.59 (main).

## 1. 지금 상태
- `main` 은 0.5.59. 열린 PR 은 **#57 (0.5.60, 쿨메신저 사진·원문 텔레그램 전달)** 하나. 머지는 사용자가 "N 머지해"라고 할 때만.
- 최근 머지 (0.5.42~0.5.59): 출결 월별 목록, 전용 창, 자동 AI 요약, 텔레그램 결석계 달력, 학부모 확인 후 발급, 명령 낱말 판별, 새 버전 알림·텔레그램 업데이트, 주간 계획 ①(읽기)·두 번 눌러 일정 추가, 지난 접속 이후 브리핑, 화면 보내기 범위(확장 프로그램 0.2.x), 나이스 입력 칸 채우기(0.5.56·0.5.57, 현재 보류 여부 사용자 확인 대기), 팝업 양식·수신함 지우기·설정 간소화, 텔레그램 중복 신청 확인.
- 배포 확인은 `desk-latest` 설명의 버전과 커밋으로 합니다. 머지 뒤 윈도우용 ZIP 워크플로(`desk-portable`)가 성공했는지도 봅니다.

## 2. 사용자가 정한 것 (바꾸기 전에 확인)
- 머지 = 배포. 사용자가 "머지해"라고 말한 PR 만 머지. 개발 대화는 머지하지 않음.
- 학생 이름·조퇴 사유·공문·쪽지는 이 PC 밖으로 보내지 않는 것이 원칙. 예외는 `AGENTS.md`에 적힌 것만:
  - 조퇴·외출증 학부모 확인 알림의 학부모 연락처 (2026-10-30)
  - 발급 뒤 '웹 링크 받기'의 학생용 링크, 사유 제외 (2026-10-30)
  - 쿨메신저 쪽지 **원문** 텔레그램 전달, 설정 `telegram_cool_text`, 기본 끔 (2026-11-02)
- 쿨메신저 **사진** 텔레그램 전달(`telegram_photos`)은 PR #57 에서 **기본 켜짐**으로 되어 있음. 사용자가 기본값을 정하지 않았으니 머지 전에 확인할 것.
- 나이스 입력 칸 채우기(0.5.56·0.5.57)는 사용자가 "잠정 보류"로 정함. 이미 배포되어 있음. 되돌릴지, 설정 스위치를 둘지, 그대로 둘지는 사용자 결정 대기.
- 설명·알림·화면 문구는 한국어, 쉬운 말.

## 3. 아직 확인되지 않은 것 (실제 PC·폰에서 필요)
- 전용 창: 윈도우 실물에서 열기와 열린 창 앞으로 가져오기 (`window.py` 의 SetForegroundWindow).
- 자동 AI 요약: 실제 LM Studio 속도와 품질, 처음 켠 날 대량 요약 (`ai.py`).
- 텔레그램: 날짜 달력(결석계·조퇴·외출), 학부모 확인 흐름, 중복 신청 경고, 업데이트 단추와 다시 켜짐, 명령 판별.
- 주간 계획: 학사일정·여러 학년 시간표로 수업 없는 날 판정, 1주/2주 기본값.
- 나이스: 실제 화면의 칸 찾기, 이름표 검사(근사치), 체크박스, 탭 전환 시 확인 창 흐름. 확장 프로그램 `neis.js`·`neisfill.py`.
- 확장 프로그램 버전 0.3.x 는 선생님 PC 에서 ↻ 로 다시 불러와야 적용됨.
- 에듀파인 공문 본문은 그림(OZ 뷰어)이라 글을 못 읽음. 공문은 기존 '에듀파인 공문 저장 폴더' 수집을 씀.

## 4. 작업 방법 (코파일럿과 같이 쓸 때)
- 브랜치: `claude/...`, `copilot/...` 등 짧은 이름. 같은 브랜치를 두 도구가 동시에 고치지 않는다.
- 시작할 때 `git fetch origin main` 과 `git status`. 모르는 미커밋 변경은 지우지 말고 출처를 확인.
- 시험: `python -m unittest discover -s tests -t .` 와 `node --test tests/pass-codec.test.cjs tests/browser-ai.test.cjs tests/capture-extension.test.cjs` (CI 와 같은 방식). 폴더 전체를 `node --test tests/` 로 돌리면 CI 와 다르게 실패할 수 있음.
- 버전: `desk/__init__.py` 한 줄. PR 이 겹치면 머지 직전에 큰 쪽 +1. 기록(`CHANGELOG`·`DESIGN`)은 양쪽 줄을 모두 살림.
- PR 설명: 요구사항, 바꾼 내용, 실행한 테스트, 확인하지 못한 것. 실제 PC·나이스·텔레그램에서만 알 수 있는 것은 "확인하지 못한 것"에 씀.
- 개인 정보가 든 실제 자료는 개발 폴더에 가져오지 않는다. 가짜 자료로 시험.
- 텔레그램 봇 토큰은 개발 폴더에 넣지 않는다 (같은 봇을 두 곳에서 켜면 Conflict).

## 5. 파일 위치 빠른 안내
- 서버·API: `desk/server.py`. 수집: `desk/collect.py`. 텔레그램: `desk/telegram.py`. 설정 키: `desk/config.py`.
- 화면: `web/js/views/*.js` (설정은 `settings.js`, 수신함 `inbox.js`, 주간 계획 `week.js`, 나이스 입력 `neisfill.js`).
- 확장 프로그램: `browser-extension/` (`capture.js`·`neis.js`·`background.js`·`popup.js`).
- 윈도우용 ZIP: `tools/build_portable.py`, 워크플로 `.github/workflows/desk-portable.yml`.
