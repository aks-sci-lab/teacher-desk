# 설계 결정 (업무 데스크)

기능을 고치기 전에 해당 항목을 읽으세요. 새 결정은 여기에 한 항목씩 더하고, 항목 앞에 버전·사용자 요청을 적습니다. 요약 규칙·작업 방식은 `AGENTS.md` 에 있습니다.

- 일반 질문 AI 선택(0.5.29, 사용자 승인: 정보 보호 유지): `ai_provider`는 로컬·브라우저 내장·OpenAI·Claude·Gemini 중 일반 질문용으로만 선택. 브리핑·업무자료 검색은 기존 로컬 경로 유지. `desk/providers.py`는 질문에 DB 자료를 붙이지 않으며 외부는 매번 명시 동의, 명단 이름·연락처·수신자료 복사 보조 검사(완전 판별 아님), 고정 HTTPS API·리디렉션 금지·자동 재시도 없음. API 키는 Config 비밀값으로 화면·로그에 노출하지 않음. 브라우저 `LanguageModel`은 지원 검사·영어 질문만(한국어 공식 지원 미보장), 클릭 때 모델 준비·요청 후 세션 정리, 닫힌 브라우저·텔레그램에는 사용 불가. 텔레그램 `/ask`는 별도 일반 질문이며 외부는 10분·1회 확인. 기존 AI 검색과 구별.
- 로컬 AI 설치 도우미(0.5.28): `desk/localai.py`가 Windows CIM으로 CPU·RAM·GPU 이름만, 디스크 여유는 앱 드라이브에서 확인. 4B(Q4_K_M)는 RAM 12/가용 6/디스크 7GB, 8B는 24/12/12GB 이상일 때 추천. 인증 API로 CP949·CRLF 배치파일 다운로드만, 서버가 설치를 몰래 실행하지 않음. 배치는 사용자 승인 → winget LM Studio 또는 공식 설치 안내 → 고정 모델 URL 다운로드 → lms load(12288 context) → 127.0.0.1 전용 서버. 설정 적용은 지정 모델과 가짜 문장 답변 확인 뒤에만. 실사용 AI·다른 모델을 강제 종료하지 않음.
- 텔레그램 편의(0.5.28): /menu 지속 키보드, /cancel 입력·미발급 선택만 취소, /status 연결 안내, /lessons. `Bot.dialog`는 연결 계정의 현재 입력만 PC 메모리에 10분 보관(명단 이름은 전송하지 않음), 무작위 콜백·단계 검사·확인 1회. 결석계는 번호→종류→날짜→수업일 미리보기→저장, 저장 직전 명단·학사일정 재검사. 일반 입력의 명령/AI 선택에 AI 없는 검색도 제공. 이미 진행 중인 AI·인쇄·저장된 기록은 취소로 되돌리지 않음.
- 첨부 원문(0.5.27, 사용자 선택): 수집 폴더의 HWP·HWPX·PDF·XLSX 항목은 원문 창에서 원본 서식을 우선 표시. PDF는 그대로, 나머지는 인증된 `POST /api/items/<id>/preview` → `desk/preview.py` → 이 PC의 한글·Excel COM을 PowerShell로 실행해 PDF로(별도 Python 패키지 없음). 작업용 복사본만 열고 임시 자료는 요청 뒤 삭제, 한 번에 하나·90초 제한, 오류는 화면에 표시. Excel은 매크로·이벤트·외부 링크 업데이트를 끄고 읽기 전용. 쪽지 본문과 첨부를 추측으로 연결하지 않고 받은 파일 폴더에서 별도 자료로 수집. 텔레그램 수집 알림·요약·수집 답에도 원본 받기 단추, 건수만이면 숨김, 원본은 명시적으로 누를 때만 전송.
- 로컬 우선: 브라우저는 PC 파일을 못 읽으므로 Python 로컬 서버가 쿨메신저·에듀파인 폴더를 읽는다.
- 쿨메신저 쪽지: `%LOCALAPPDATA%\CoolMessenger\Memo\<이름>.udb` (사용자 확인). 이름만 넣거나 파일 경로를 직접 지정. `.udb` 구조는 미확인이라 SQLite 로 보고 표·열 자동 인식, 복사본을 읽기 전용으로. 내용이 `{COMP}` 로 시작하면 base64(zlib(UTF-16LE HTML)) 압축 (사용자 화면으로 확인, 0.4.1). 사진(0.5.2): HTML `<img src>`·RTF `\pngblip/\jpegblip` 를 `items.images`(JSON)에 저장. 인터넷 주소는 화면이 직접(CSP img-src http/https 허용), 쪽지 안 그림·PC 파일은 `/api/items/<id>/images/<n>` 로 (쿨메신저 폴더·.udb 폴더·받은 파일 폴더 안의 그림 파일만). 실제 저장 형식은 미확인 → 연결 확인이 사진 종류(개수만)를 보여 줌.
- 내가 보낸 쪽지(0.5.31, 사용자 요청: .udb 에 내가 보낸 메시지도 있음): 보낸 사람 열(이름 열을 `…key`·`…id` 보다 먼저 고름)의 값이 '나'(설정의 쿨메신저 이름, 없으면 .udb 파일 이름)와 같으면 `source='cool_sent'` 로 저장 — 일정 후보 없음·읽음 상태·새 자료 수/알림/AI 요약/검색 범위(`source IN ('cool','edufine')`)에 안 들어감. 수신함 필터 '쿨메신저 보냄'. 이름이 같을 때만 나눔(추측 안 함). **실제 .udb 열 이름은 미확인**: 올려 준 변환기에서 `senderkey`·`cclist`·`referencelist`·`messagecategory`·`ismoved`·`ischecked`·`deleteddate`·`memoid`·`linkurl`·`filehost` 열이 있다는 것만 앎(변환기는 이 열들을 뺌). 연결 확인이 '내가 보낸 쪽지 n개'를 보여 주며 0개면 파일 구조를 보내 달라고 안내. 이미 `cool` 로 들어간 예전 쪽지는 옮기지 않음. 채팅형 보기·상대별 묶기는 구조 확인 뒤.
- 브리핑 오늘 마감·모두 읽음(0.5.32, 개선 6·8): 마감은 기간이면 **끝나는 날** 기준 — `today_summary` 의 `due_today`(오늘 끝나는 미완료 마감)는 별도 '오늘 마감' 카드·텔레그램 '⏰ 오늘 마감'으로 강조하고 '오늘 일정'에서는 뺌(중복 없음), '7일 안 마감'·'지난 마감'도 끝 날짜로. 수신함 '안 읽은 n건 모두 읽음'은 화면에 보이던 안 읽은(`status='new'`) id 만 `POST /api/items/mark-read` 로 읽음 처리(일정 등록·완료 처리는 그대로, 그 사이 새로 온 자료는 안 읽음). 개선 1(결석계 월별)은 0.5.24~25 월별 통계(월과 겹치는 기간·실제 결석일)로 이미 있음.
- 시간표 학사일정 판정(0.5.33, 개선 2): `timetable.day_note(day_events, 날짜, 학년)` 하나로 화면(브리핑 '오늘 내 수업' 태그)·텔레그램(`내일 수업`·`오늘`·AI 답의 시간표)·수업 시작 알림이 같은 판정을 씀 — **off**(휴일·휴업 등 `P_OFF`, 또는 그 학년이 적힌 행사 → 수업 없음, 알림은 보내지 않음), **maybe**(학년이 안 적힌 행사·체육·고사 등 → 일부 교시가 바뀔 수 있어 '확인 필요', 알림은 보내되 경고를 덧붙임), 다른 학년 행사는 무시. 수업 교체 후보의 막는 날 판정(`block_reason`)은 예전 그대로(모든 P_BLOCK). 불확실한 것을 수업 없다고 단정하지 않음.
- 할 일 메모(0.5.34, 개선 7): `todo_notes` 표(할 일 id·글·쓴 시각·고친 시각, 할 일을 지우면 함께 지워짐, 이 PC 에만). `POST /api/todos/<id>/notes`·`PATCH/DELETE /api/todo-notes/<id>`, `queries.todos` 가 `notes` 를 붙여 줌. AI 요약을 다시 만들어도 `todos` 행이 그대로라 메모도 그대로. 화면은 할 일 줄의 '메모' 단추로 펼침(메모가 있으면 늘 보임, 끝낸 할 일은 접힘).
- 항목별 AI 요약(0.5.35, 개선 3): 수신 항목 화면 '내용 요약' 위의 [AI 로 요약하기]를 눌렀을 때만(자동 아님 — 8845HS 에서 한 건 20~30초) `ai.ItemJob` 이 뒤에서 한 번에 하나, 이 PC 의 LM Studio 로만, 학생 이름은 가려서 요약해 `items.ai_summary`(+`ai_summary_hash`=원문 정규화 해시·`_at`·`_model`)에 **원문과 따로** 저장. 원문이 같으면 저장본을 쓰고 바뀌었으면 '다시 요약' 안내(stale), 실패는 화면에 그대로(예전 요약은 남김), 다시 요약은 force. 화면은 3초마다 상태 확인. 브리핑의 1주일 요약(`meta.ai_weekly`)과는 별개.
