# 🗂 교사 업무 데스크

학교 PC 에서 켜 두고 쓰는 **업무 관리 웹앱**입니다. 브라우저로 열어 쓰지만, 자료는 인터넷이 아니라 **이 PC 안에만** 저장됩니다.

| 기능 | 하는 일 |
|---|---|
| 🎫 출결 | 조퇴증·외출증·결석계를 한 메뉴에서 작성·기록·인쇄하고 월별 마감 참고 통계를 확인 |
| 📥 수신함 | 쿨메신저 메시지·에듀파인 공문에서 날짜·마감·시각을 찾아 분류·요약. **☑ 체크한 메시지의 일정만** 달력·브리핑에 들어감 (직접 붙여넣은 것은 바로) |
| 🤖 AI 요약 | 브리핑에서 지난 1주일 쿨메신저·업무포털 내용을 **이 PC 의 LM Studio** 로 요약 (선택, 내용이 PC 밖으로 나가지 않음) |
| 👁 실시간 감시 | 켜 두는 동안 쿨메신저 쪽지 파일과 에듀파인 공문 저장 폴더가 바뀌면 바로 읽음 (20초마다 파일의 바뀐 시각만 확인) |
| 🔄 예약 수집 | 9시·12시·15시에도 한 번씩 읽어 놓친 것을 잡음 (PC 가 꺼져 있었으면 켜진 뒤 한 번) |
| ⬆ 자동 업데이트 | `start-desk.bat` 으로 켤 때 새 버전이 있으면 받아서 바꾼 뒤 다시 켬, 없으면 바로 켬 |
| 📅 달력 | 한 달 보기, 일정 추가·끝냄 표시, **학사일정 가져오기**(엑셀·한글·PDF·붙여넣기·나이스), 구글 캘린더용 `.ics` 내보내기 |
| 📋 브리핑 | 지난 마감·오늘 일정·7일 안 마감·오늘 조퇴/외출·새 자료를 한 화면에 |
| 📱 텔레그램 | 수집 후 알림, 폰에서 `오늘`·`마감`·`새로고침`·`요약` 명령, 증 발급 후 기본 프린터 인쇄·학생용 웹 링크 받기 |
| 🔍 검색 | 메시지·공문 내용(문서번호·분류 포함), 일정, 조퇴·외출 기록(사유·메모), 학생 명단 전체 검색. 띄어 쓰면 모든 낱말이 들어간 것만 (Ctrl+K) |

결석계는 일반 기본 양식입니다. 학교 공식 양식이 따로 있으면 그 서식에 맞춰 추가해야 하므로, 공식 양식 파일을 제공해 주세요.
월별 통계에서 결석 일수는 주말과 가져온 학사일정의 공휴일·휴업일·방학을 제외합니다. 취소된 조퇴·외출증은 집계하지 않습니다. **학생별 숫자나 전체 합계를 누르면 날짜·종류·사유**가 나오며, CSV 파일로도 내려받을 수 있습니다. 학사일정을 고치면 실제 결석일과 통계에도 반영됩니다.

텔레그램에서 `결석계 김가온 7 병결 2026-10-29~2026-11-03`처럼 **이름·번호·종류·날짜**를 보내면 앱에 저장됩니다. 종류는 `병결`·`인정결`·`기타결`·`미인정결` 중 하나이며, 날짜는 `10/29~11/3`처럼 연도를 생략할 수도 있습니다(현재 연도 기준, 연말에서 연초로 넘어가는 기간 지원). 학생 명단의 이름·번호가 일치해야 하고 **해당 학년도 학사일정을 먼저 가져와야** 합니다. 텔레그램으로는 결석계를 인쇄하지 않으며, 답장에 학생 이름과 사유를 다시 쓰지 않습니다. 입력 메시지 자체는 텔레그램에 남으므로 자세한 사유는 앱에서만 적으세요.

텔레그램에서 목록에 없는 말이나 잘못된 `/명령`을 보내면 **명령어 목록과 선택 단추**를 보여 줍니다. 명령 단추를 고르거나 **이 내용으로 AI 검색**을 누르세요. 선택 전에는 AI를 실행하지 않으며, AI가 꺼져 있으면 검색한 자료만 보여 줍니다. 선택 요청은 최근 10개만 유지하고 앱을 종료하면 사라집니다.

## 1. 내려받기 (처음 한 번, Python 설치 필요 없음)

1. 아래 주소에서 **teacher-desk-windows.zip** 을 내려받습니다.
   https://github.com/aks-sci-lab/teacher-desk/releases/download/desk-latest/teacher-desk-windows.zip
2. 바탕화면 등 원하는 곳에 **압축을 풉니다.** `TeacherDesk` 폴더가 생깁니다.
   - 안에 Python(`teacher-desk\python`)과 PDF 읽기 도구(`teacher-desk\lib`)가 들어 있어 따로 설치할 것이 없습니다.
   - `teacher-desk` 와 `pass` 폴더는 **같은 자리에 그대로** 두세요.
3. 바탕화면 바로 가기가 필요하면 `teacher-desk\make-desktop-shortcut.bat` 을 두 번 누릅니다.

### 새 버전으로 바꾸기

0.4.0 부터는 **켤 때 저절로** 바뀝니다. `start-desk.bat` 을 누르면 먼저 새 버전이 있는지 확인하고(몇 초),
- 없으면 바로 켜지고,
- 있으면 "업무 데스크 업데이트" 창이 떠서 새 버전을 받아 **프로그램 파일만** 바꾼 뒤 다시 켭니다.
- 인터넷이 안 되면 확인을 건너뛰고 지금 버전으로 켭니다. 끄려면 ⚙ 설정 → ⬆ 업데이트.
- **켜 둔 채로도 새 버전을 알려 줍니다** (0.5.38~). 켠 뒤 6시간마다 확인해서 새 버전이 있으면 화면 아래 막대에 **⬆ 새 버전 … · 업데이트** 가 나타납니다. 누르거나 ⚙ 설정 → 업데이트의 **[지금 업데이트]** 를 누르면 업무 데스크가 1~2분 꺼졌다가 새 버전으로 저절로 다시 켜집니다 (프로그램을 따로 끌 필요 없음, 수집·AI 요약이 도는 중이면 먼저 물어봅니다). 바로 알고 싶으면 **[새 버전 확인]**.
- 바꾸는 것은 항상 누를 때만입니다. 켤 때의 자동 확인은 예전처럼 새로 켜질 때 동작합니다.

학생 명단·발급 기록·수신함(`data` 폴더)과 설정(`config.json`)은 그대로 남습니다. 업데이트 기록은 `data\update.log`.

> 0.3.x 를 쓰고 있다면 **한 번만** 업무 데스크 창을 닫고 `teacher-desk\update-desk.bat` 을 두 번 눌러 0.4.0 으로 바꾸세요. 그다음부터는 저절로 됩니다. (`update-desk.bat` 은 손으로 바꾸고 싶을 때 언제든 쓸 수 있습니다.)

> `update-desk.bat` 이 없는 예전 버전(2026-10-27 이전에 받은 것)은 한 번만 손으로 바꿉니다: 위 주소에서 새 ZIP 을 받아 풀고, 예전 폴더의 `teacher-desk\data` 폴더와 `teacher-desk\config.json` 을 새 폴더의 `teacher-desk` 안으로 옮기세요.

> 개발용: Python 이 설치된 PC 에서는 저장소의 `teacher-desk` 폴더를 그대로 실행해도 됩니다 (PDF 는 `pip install pypdf`).

## 2. 켜기

`start-desk.bat` 을 두 번 누르면 백그라운드에서 켜지고 브라우저가 자동으로 열립니다 (http://127.0.0.1:8770). 시작할 때 잠깐 나타나는 명령 창은 저절로 닫힙니다. 다시 누르면 이미 실행 중인 앱의 화면만 열며 서버·텔레그램을 중복 실행하지 않습니다.

- 윈도우가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

- **브라우저를 닫아도 예약 수집·텔레그램은 계속 동작합니다.** 완전히 끄려면 **설정 → 프로그램 실행 → 프로그램 종료**를 누르세요. PC를 종료하면 함께 꺼집니다.
- PC 를 켤 때마다 자동으로 켜려면: `Win + R` → `shell:startup` 입력 → 열린 폴더에 `start-desk.bat` 의 **바로 가기**를 넣습니다.

## 3. 처음 설정 (⚙ 설정)

칸을 고치고 다른 곳을 누르면 그 칸은 바로 저장됩니다 ('… 저장됨' 알림). 텔레그램 토큰·나이스 인증키만 **설정 저장** 단추로 저장하세요.

1. **학교·학급**: 학교 이름, 학년, 반, 담임 이름 (조퇴증·외출증에 인쇄됨)
2. **에듀파인 공문 저장 폴더**: 에듀파인에서 공문을 "저장"할 때 고르는 폴더. 이 폴더에 저장한 문서만 분석합니다.
   - Synology Drive·OneDrive 를 지운 뒤 그 폴더에 남은 파일은 이름만 있는 껍데기라 읽을 수 없습니다. **폴더 확인**이 몇 개인지 알려 주며, NAS·클라우드 웹 화면에서 내려받아 보통 폴더에 두고 그 폴더를 지정하세요. 이 PC 에 있는 파일과 새로 저장하는 공문은 그대로 읽습니다.
   - `다운로드` 폴더 전체보다 **공문 전용 폴더**(예: `문서\에듀파인`)를 따로 만들어 지정하는 것을 권합니다. 다른 한글·PDF 파일까지 수신함에 들어오지 않고, 실시간 감시도 더 가볍습니다.
3. **💬 쿨메신저 이름**: 쿨메신저에 로그인하는 이름을 넣고 **🔌 연결 확인** → 최근 쪽지가 보이면 **설정 저장** (아래 설명)
4. **수집 시각**: 기본 `09:00, 12:00, 15:00`
5. **☑ 출결 → 👥 학생 명단**: 엑셀에서 번호·이름 두 칸을 복사해 붙여넣고 저장

### 💬 쿨메신저 연동

쿨메신저는 받은 쪽지를 `C:\Users\(윈도우 사용자)\AppData\Local\CoolMessenger\Memo\(이름).udb` 에 저장합니다.
윈도우 사용자 폴더(`user` 부분)는 PC 마다 달라도 업무 데스크가 자동으로 찾으므로, **이름만** 넣으면 됩니다.
이름 칸을 누르면 이 PC 에서 찾은 이름이 목록으로 나옵니다.

- 처음 연결하면 **최근 30일** 쪽지를 가져오고, 그다음부터는 새로 온 쪽지만 가져옵니다.
- 쿨메신저가 켜져 있어도 됩니다 (파일을 복사해서 읽기만 하고, 쿨메신저 파일은 바꾸지 않음).
- `.udb` 의 내부 구조는 공개 자료가 없어, 업무 데스크가 표·열 이름과 값의 모양으로 쪽지 표·내용·날짜를 스스로 찾습니다.
  **🔌 연결 확인**에서 최근 쪽지가 이상하게 보이거나 "쪽지 표를 찾지 못했습니다"가 나오면, 그 아래 **파일 구조 (내용 없음)** 를 복사해 개발 담당(Claude Code)에게 보내 주세요. 표·열 이름과 개수만 있고 쪽지 내용은 없습니다.
- 쿨메신저를 다른 곳에 설치했거나 이름으로 찾지 못하면 **(선택) 쪽지 파일 직접 지정**에서 **📂 찾아보기**로 `.udb` 파일을 고르세요. 지정하면 이름보다 우선합니다.
- (선택) **쿨메신저 받은 파일 폴더**를 넣으면 쿨메신저로 받은 한글(HWP·HWPX)·PDF·엑셀(XLSX) 파일도 함께 읽습니다. 첨부파일은 수신함의 별도 자료로 들어옵니다.
- 첨부 자료의 **원문 보기**는 원본 서식을 먼저 보여 줍니다. PDF는 그대로, 한글·엑셀은 **이 PC에 설치된 한글·Microsoft Excel**로 PDF를 만들어 표·글꼴·배치를 표시합니다. 엑셀은 저장된 인쇄 영역·페이지 설정을 따릅니다. 한글 뷰어만 있거나 한셀만 설치한 PC에서는 변환되지 않을 수 있습니다.
- 변환은 인터넷 서비스를 쓰지 않고 작업용 복사본으로 진행하며 원본 파일을 고치지 않습니다. 임시 복사본·PDF는 요청 뒤 지웁니다. 한글의 파일 접근 허용 창이 뜨면 확인해 주세요. 최대 90초 뒤에는 오류를 알리고, **추출한 글자**·**원본 프로그램으로 열기**도 선택할 수 있습니다. 암호·문서보안이 걸린 파일이나 지원하지 않는 형식은 원본 프로그램에서 확인하세요.
- 폴더·파일 칸 옆의 **📂 찾아보기**는 윈도우 찾아보기 창을 띄웁니다. 창이 안 보이면 작업 표시줄을 확인하세요.

### 📥 학사일정 가져오기

달력 → **📥 학사일정** 에서 학년도를 고르고, 세 방법 중 하나로 가져옵니다. 학교마다 양식이 달라도 되도록 **양식을 정해 두지 않고, 읽은 결과를 먼저 보여 준 뒤 고쳐서 넣는** 방식입니다.

| 방법 | 언제 | 읽는 방식 |
|---|---|---|
| 📄 파일 | 학교 홈페이지·업무포털에서 받은 학사일정 파일 | 엑셀(.xlsx·.csv)은 **달력 모양 표**(머리줄에 3월·4월…, 옆에 1~31일, 가로·세로 바뀌어도 됨, 합친 칸은 기간)와 **날짜·행사 목록**을 알아서 구별. 한글(.hwp·.hwpx)·PDF·글은 줄마다 날짜를 찾음 |
| 📋 붙여넣기 | 문서·웹페이지의 학사일정을 복사했을 때 | 글 또는 엑셀에서 복사한 표 |
| 🏫 나이스 | 양식과 상관없이 가장 확실한 방법 | 나이스에 등록된 우리 학교 학사일정을 그대로 받음 (⚙ 설정에 **나이스 인증키** 필요, open.neis.go.kr 에서 무료) |

- 연도가 없는 날짜는 학년도로 정합니다: 3~12월은 학년도, 1~2월은 다음 해.
- '2026. 3. 2.', '3. 2.(월)', '3월 2일', '4월 22일 ~ 24일', 엑셀 날짜 칸 모두 읽습니다.
- 미리보기에서 날짜·이름·분류를 고치고, 넣지 않을 줄은 체크를 끕니다. 기본으로 **같은 학년도에 전에 가져온 학사일정은 바꿉니다** (다시 가져와도 겹치지 않음).
- 가져온 일정은 달력에 **학사** 색으로 표시되고, 브리핑·텔레그램 `오늘`에도 나옵니다.
- 예전 엑셀(.xls)은 엑셀에서 '다른 이름으로 저장 → .xlsx' 로 바꿔 주세요. 스캔한 PDF(글자가 그림인 것)는 읽을 수 없습니다.

### 🌐 브라우저 단축키로 에듀파인 화면 보내기 (선택)

에듀파인(`*.use.go.kr`) 화면에서 **Alt+Shift+S** 를 누르면 지금 보이는 글이 이 PC 의 업무 데스크 수신함(출처: 에듀파인)으로 들어오고, 날짜·마감을 찾습니다. 글을 드래그로 고른 뒤 누르면 고른 글만 보냅니다. 읽은 글은 **이 PC(127.0.0.1)로만** 갑니다.

1. 업무 데스크 ⚙ 설정 → **브라우저 단축키로 화면 보내기** 에서 **[연결 켜기]** 를 누릅니다 (켜기 전에는 어떤 화면도 받지 않습니다). 연결 키가 보입니다.
2. 크롬·엣지에서 `chrome://extensions`(엣지는 `edge://extensions`) → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 설정 화면에 적힌 `teacher-desk\browser-extension` 폴더를 고릅니다.
3. 확장 프로그램 **업무 데스크로 보내기**의 옵션에 연결 키를 붙여 넣고 **[저장하고 연결 확인]**.
4. 에듀파인 화면에서 Alt+Shift+S. 화면 오른쪽 위에 "업무 데스크로 보냈습니다"가 잠깐 나옵니다. 단축키는 `chrome://extensions/shortcuts` 에서 바꿉니다.

- 확장 프로그램 아이콘을 누르면 화면 안의 프레임별 글자 수를 보여 줍니다. 글이 잘 안 읽히면 **[구조 복사]** (글 내용은 들어 있지 않음)를 개발 담당에게 보내세요.
- 업무 데스크를 업데이트하면 확장 프로그램 파일도 새로 바뀌니, `chrome://extensions` 에서 **다시 로드(↻)** 를 한 번 누르세요.
- 학교 PC 가 확장 프로그램 설치를 막으면 쓸 수 없습니다 (이때는 화면 글을 복사해 수신함에 붙여넣기).

### ☑ 수신함에서 일정 등록

자동으로 읽어 온 쪽지·공문의 날짜는 **일정 후보**로만 저장됩니다. 수신함 목록에서 **체크한 메시지의 일정만** 달력·브리핑·텔레그램 알림에 들어갑니다 (메시지를 열어 📅 일정 등록 을 눌러도 됩니다). 직접 붙여넣은 글과 학사일정은 바로 들어갑니다. 메시지 화면의 일정 후보는 한 줄씩(날짜·시각·D-day, 내용, 원문 어느 줄인지) 보이고, 원문 줄을 누르면 원문에서 그 줄을 보여 줍니다.

### 🤖 AI 요약 (선택, 이 PC 의 LM Studio)

브리핑 맨 위에 지난 1주일 쿨메신저·업무포털 내용을 AI 로 요약해 보여 줍니다. AI 는 이 PC 에서 돌기 때문에 내용이 밖으로 나가지 않습니다.

1. LM Studio 에서 한국어가 되는 모델을 받아 불러옵니다. 메모리 24GB PC 라면 Qwen3 8B·Gemma 3 12B·EXAONE 3.5 7.8B (Q4) 정도가 알맞습니다.
2. LM Studio 왼쪽 **Developer(개발자)** → **Start Server** 를 켭니다 (주소 `http://127.0.0.1:1234`).
3. ⚙ 설정 → 🤖 AI 요약 → **🔌 연결 확인** → "브리핑에서 AI 요약 쓰기" 체크 → 설정 저장.

**꼭 할 일로 옮기기**: 브리핑의 '다가오는 행사·회의'·'알아 둘 내용' 줄, '7일 안 일정' 같은 카드의 일정, '새로 받은 자료' 를 **꼭 할 일 칸으로 끌어 놓으면** 옮겨집니다 (폰처럼 끌기 어려우면 줄의 **[할 일로]**). 꼭 할 일 칸에서 직접 쓸 수도 있고, ☑ 로 끝냄, ✕ 로 지우면 AI 요약 줄은 원래 칸으로 돌아갑니다. AI 요약을 안 쓰면 '꼭 할 일' 카드로 따로 보입니다. 텔레그램 `브리핑` 에도 나옵니다. 내가 넣은 할 일은 왼쪽 ⠿ 를 잡고 **위아래로 끌어 순서를 바꿀** 수 있고 (폰에서는 ▲▼), 구분선 아래 'AI 요약이 찾은 할 일' 을 위로 끌어 올리면 그 자리에 들어갑니다. AI 가 요약하는 동안에도 있던 요약은 그대로 보이고 위에 작은 진행 줄만 나옵니다.

브리핑을 그날 처음 열 때 1주일 치를 한 번 **전체 요약**하고, 그 뒤에 새 쪽지·공문이 들어오면 **새 것만 요약**해 같은 칸(꼭 할 일·행사·알아 둘 내용)에 **새** 표시로 합쳐 보여 줍니다 (보통 1분 안쪽, 자동으로는 10분에 한 번까지). 요약 칸에 '🆕 요약 뒤 새 자료 n건' 이 보이면 **새 것만 요약**·**전체 다시 요약** 중에 고를 수 있습니다.

요약이 끝나면 그 결과로 수신함 메시지의 **분류와 일정 후보도 정리**합니다 (AI 에게 따로 묻지 않아 시간이 더 들지 않음). '꼭 할 일'에 나온 메시지는 제출·마감, 요약에 나온 날짜가 일정 후보에 없으면 🤖 표시와 함께 더합니다. 달력에 넣은(체크한) 메시지는 건드리지 않습니다. 요약은 업무 데스크가 뒤에서 만들므로 기다리는 동안 다른 화면을 써도 됩니다 (8845HS 내장 그래픽·12B 모델로 4~5분, 최대 15분까지 기다림). 오래 걸리면 ⚙ 설정의 **보내는 양 → 짧게** 를 고르세요.

**내가 보낸 쪽지**: 쿨메신저 쪽지 파일에는 내가 보낸 쪽지도 들어 있습니다. 보낸 사람이 **쿨메신저 이름과 같으면** 수신함의 **쿨메신저 보냄** 으로 따로 모읍니다 (일정 후보·새 자료 알림·AI 요약·검색에는 쓰지 않음). 설정의 **연결 확인**에서 '내가 보낸 쪽지 n개'가 보이면 구분되고 있는 것이고, 0개이면 보낸 사람 열에 이름이 없는 것이니 '파일 구조'를 복사해 보내 주세요. 이미 받아 둔 예전 쪽지는 옮기지 않습니다.

**오늘 마감**: 브리핑에 '오늘 마감' 칸이 따로 생깁니다. 기간이 있는 마감(예: 11/2~11/13)은 **끝나는 날**에 '오늘 마감'으로 나오고, 오늘 일정에서는 빠집니다. 수신함 목록 위의 **'n건 모두 읽음'** 은 지금 보이는 안 읽은 항목만 읽음으로 바꿉니다 (일정 등록·완료는 그대로).

**할 일 메모**: 꼭 할 일 줄의 **메모** 를 눌러 그 할 일에 짧은 메모를 붙일 수 있습니다 (쓴 시각이 같이 남고 ✎ 로 고치고 ✕ 로 지움). 이 PC 에만 저장되며 AI 요약을 다시 만들어도 그대로입니다.

**항목 하나만 AI 요약**: AI 요약을 켜 두었다면 수신함 항목의 **내용 요약** 위에 **[AI 로 요약하기]** 가 보입니다. 누르면 그 항목 하나를 이 PC 의 AI 가 뒤에서 요약해 (몇 분 걸릴 수 있음) 원문과 따로 저장합니다. 원문이 바뀌지 않으면 저장한 것을 다시 보여 주고, 실패하면 이유가 그대로 나옵니다.

**수신함 자동 AI 요약** (0.5.44, 기본 켜짐): AI 요약을 켜 두면 최근 7일 안에 받은 쪽지·공문을 **뒤에서 한 건씩 저절로** 요약합니다 (이 PC 의 LM Studio 로만, 학생 이름은 가려서, 한 건에 20~30초). 수신함 목록에는 제목 아래 **AI 한 줄 요약**이 보이고, 항목을 열면 **AI 요약이 맨 위**에 나오며 규칙으로 뽑은 줄은 "기본 요약 보기"로 접혀 있습니다. 연 항목은 줄 맨 앞에서 먼저 요약합니다. 날짜·마감(일정 후보)은 AI 가 아니라 **규칙으로만** 뽑으므로 AI 가 날짜를 틀려도 달력에는 영향이 없습니다. LM Studio 가 꺼져 있으면 오류를 쌓지 않고 조용히 쉬었다가 5분 뒤 다시 시도합니다. 자동으로 하고 싶지 않으면 ⚙ 설정 → 업무자료 AI 요약의 **새 수신 항목을 자동으로 AI 요약**을 끄세요 (그러면 [AI 로 요약하기]를 눌렀을 때만 요약).

## 4. 텔레그램 연결 (선택)

1. 텔레그램에서 **@BotFather** 를 찾아 `/newbot` 을 보내고 안내대로 봇 이름을 정하면 **토큰**을 줍니다.
2. ⚙ 설정 → 텔레그램 → 봇 토큰에 붙여넣고 **설정 저장**
3. 설정 화면에 나온 `/start 123456` 을 만든 봇에게 보내면 연결됩니다. **이 코드를 보낸 계정 하나만** 명령할 수 있습니다.

| 폰에서 보내는 말 | 답 |
|---|---|
| 그냥 묻기 `다음 주 연수 언제야?` | 맞는 쪽지·공문·일정을 찾아 **이 PC 의 AI(LM Studio)** 가 읽고 답함 (근거 자료 번호와 [원문]·[파일] 단추). AI 를 안 켜면 찾은 자료만 |
| `브리핑` | 오늘 일정·마감·내 수업 + 지난 1주일 AI 요약 |
| `검색 낱말` (또는 낱말만) | 제목·요약 두 줄·가까운 마감 + [원문]·[파일] 단추 |
| `원문 2` · `파일 2` | 브리핑·검색의 2번 자료 원문 글 · 원본 파일 (달라고 할 때만 보냄) |
| `조퇴 7 13:30` · `외출 7 13:30 14:30` · `7번 조퇴 1시 반` | 사유를 고른 뒤 **인쇄 · 웹 링크 · 둘 다 · 안 함** 중에서 고름 |
| `내일 수업` · `금요일 시간표` | 내 수업 (시간표를 불러왔을 때) |
| `오늘` · `마감` · `새로고침` · `요약` · `도움말` | 오늘 일정·인원 · 7일 안 마감 · 지금 수집 · 최근 자료 3건 · 명령 안내 |

- **학교 PC 가 켜져 있고 업무 데스크가 실행 중일 때만** 답합니다. AI 답은 1~2분 걸립니다.
- 학생 이름·조퇴 사유는 텔레그램으로 보내지 않습니다. 증 발급은 번호로 하고, 답장에는 '김○○' 처럼만 씁니다. 학생 명단·조퇴 기록은 텔레그램 검색에서 빠집니다.
- 증을 발급하면 단추 네 개가 나옵니다: **🖨 기본 프린터로 인쇄**, **🔗 웹 링크 받기**, **인쇄 + 웹 링크**, **아무것도 안 함**. 인쇄를 고르면 Windows 기본 프린터로 2장을 바로 보냅니다 (Edge 또는 Chrome 필요, 인쇄 창은 뜨지 않음). 인쇄 요청은 **10분 안에 처리되지 않으면 사라집니다** (실패한 요청이 나중에 다시 인쇄되지 않게). 발급 기록을 열어 다시 인쇄할 수도 있습니다.
- **웹 링크**에는 학생 이름·번호·날짜·시각·학교·학급이 들어 있고 **사유는 빠집니다**. 이 링크는 텔레그램 서버를 거치므로 학생에게만 전달하세요. 링크는 설정의 공유 페이지 주소로 만들어집니다.
- 쪽지·공문 **원문과 원본 파일은 [원문]·[파일] 단추나 '원문 n'·'파일 n' 으로 달라고 할 때만** 보냅니다 (원문 안의 이름은 그대로).
- 새 자료 수집 알림·최근 자료(`요약`)·수집 명령의 결과에도 **[원본 파일 받기]** 단추가 표시됩니다. 단추를 눌러야 원래 HWP·HWPX·PDF·XLSX 등을 보내며, 미리보기용 PDF로 바꿔 보내지 않습니다. 알림 설정이 '건수만'이면 제목·파일 단추를 표시하지 않습니다. 지정한 수집 폴더에서 원본을 옮기거나 지우면 받을 수 없습니다.
- "수집 알림에 담을 내용"을 **개수만**으로 바꾸면 새 자료 알림에 공문 제목도 보내지 않습니다.

### 명령어를 외우지 않고 쓰기

- `메뉴` 또는 `/menu`를 보내면 대화창 아래에 브리핑·출결·검색·수업 단추가 계속 표시됩니다. `도움말`은 자세한 명령 목록입니다.
- **조퇴증·외출증**만 보내면 번호 → 시각 → 사유 순서로 안내합니다. **지금 시각으로**도 고를 수 있으며, 외출 복귀는 나가는 시각보다 뒤여야 합니다. 기존 `외출 7 13:30 14:30` 같은 한 줄 명령도 그대로 됩니다.
- **결석계**만 보내면 번호 → 종류 단추 → 날짜 → 수업일 수 확인 → **앱에 저장** 순서입니다. 이름을 폰에 쓰지 않아도 PC 명단에서 찾습니다. 저장을 눌러야 기록되며 인쇄는 하지 않습니다. 명단·학사일정이 필요합니다.
- **자료 검색**은 찾을 낱말을 물어보고 AI 없이 자료만 검색합니다. 알아듣지 못한 질문에는 **AI 검색 / AI 없이 자료 검색** 중 고를 수 있습니다.
- **취소** 또는 `/cancel`은 진행 중인 입력·아직 발급 전인 선택을 취소합니다. 이미 저장한 기록·시작한 인쇄·AI 답변은 취소하지 않습니다. 단계별 입력은 10분이 지나면 만료되고, 재시작·연결 해제 때 사라집니다.
- **상태** 또는 `/status`에서 AI 연결·시간표 준비 상태를 확인합니다. 원문·원본 파일은 여전히 따로 요청해야 보냅니다.

### 로컬 AI 쉽게 설정하기

설정 → **업무자료 AI 요약**에서 순서대로 누르세요.

1. **PC 사양 확인·모델 추천**: CPU·메모리·현재 사용 가능한 메모리·GPU 이름·남은 디스크를 이 PC에서만 확인합니다. 사용자 이름·기기 일련번호는 수집하지 않습니다.
2. **설치·실행 배치파일 받기**: 추천 모델을 고르고 내려받은 `setup-local-ai.bat`을 실행합니다. LM Studio가 없으면 설치 여부를 묻습니다. 설치 직후에는 LM Studio를 한 번 열어 초기 설정을 마친 뒤 배치파일을 다시 실행하세요. 학교 설치 제한이 있으면 관리자에게 요청해야 할 수 있습니다.
3. 배치파일에서 다운로드·실행을 승인하면 고정된 Hugging Face 모델 파일을 받고 LM Studio를 **127.0.0.1 전용**으로 실행합니다. 이미 같은 모델이 실행 중이면 재사용하고, 다른 모델을 강제로 내리거나 기존 서버를 종료하지 않습니다. 외부에 공개된 포트는 거절합니다.
4. 설정 화면의 **연결 확인 후 적용**을 누릅니다. 선택한 모델의 목록과 짧은 시험 답변까지 확인한 뒤에만 AI 주소·모델·켜기·보내는 양('짧게')을 저장합니다. 시험에는 학교 자료를 보내지 않으며 실패하면 기존 설정을 유지합니다.

추천은 **Qwen3 4B Q4_K_M**(전체 메모리 12GB·사용 가능 6GB·디스크 7GB 이상), **Qwen3 8B Q4_K_M**(24GB·12GB·12GB 이상) 두 가지입니다. 이는 품질·속도를 보장하는 수치가 아닌 보수적인 기준입니다. GPU 공유 메모리를 전용 VRAM으로 잘못 계산하지 않습니다. 디스크는 앱이 있는 드라이브 기준이라 모델 저장 위치가 다르면 그쪽도 확인해야 합니다. 여유 사양이 부족하면 다른 프로그램을 닫고 다시 확인하세요.

설치와 모델 다운로드에는 인터넷이 필요하지만 공문·학생 자료를 다운로드 사이트로 보내지 않습니다. 업무자료 추론은 기존 원칙대로 이 PC의 LM Studio에서만 합니다. 재부팅 뒤에는 배치파일을 다시 실행해 AI를 켤 수 있습니다. 자동 시작 등록은 하지 않습니다. 기존 수동 LM Studio 설정도 그대로 사용할 수 있습니다.

명령 기준: [LM Studio CLI](https://lmstudio.ai/docs/cli), [모델 다운로드](https://lmstudio.ai/docs/cli/local-models/get), [로컬 서버](https://lmstudio.ai/docs/cli/serve/server-start). 오래된 LM Studio에서 명령을 지원하지 않으면 최신 버전으로 업데이트하세요.

### 일반 질문용 AI 선택 (로컬·브라우저 내장·외부 API)

**AI 질문** 메뉴 또는 설정 → **AI 사용 방식**에서 선택합니다. 이 선택은 일반 질문에만 적용됩니다. **공문·쪽지 요약, 텔레그램 업무자료 검색은 언제나 로컬 AI**를 사용합니다. 일반 질문에는 수신함·명단·출결·이전 대화를 자동으로 붙이지 않습니다.

- **로컬**: 설정의 LM Studio 주소와 모델을 재사용합니다. 브리핑 AI 켜기와 별개로 일반 질문을 보낼 수 있습니다.
- **브라우저 내장**: 현재 브라우저의 `LanguageModel` API 지원 여부를 **브라우저 지원 확인**으로 검사합니다. 기기 내에서 실행하지만 최초 모델 다운로드에는 인터넷·저장 공간이 필요합니다. 브라우저·PC 사양에 따라 사용할 수 없으며, Chrome 공식 지원 언어에 한국어가 없어 현재는 **영어 질문만** 제공합니다. 지원되지 않으면 로컬이나 외부 API를 직접 선택해야 하며 자동 전환하지 않습니다. 브라우저를 닫은 동안이나 텔레그램에서는 실행할 수 없습니다.
- **외부 API — GPT / Claude / Gemini**: 서비스별 **정확한 모델 이름과 API 키**를 넣고 **선택·API 설정 저장**을 누릅니다. API 키는 이 PC의 설정 파일에 저장하며 화면·로그·텔레그램으로 다시 보내지 않습니다. 키 칸을 비워 저장하면 유지하고, **API 키 삭제**로 지웁니다. Windows 계정과 설정 파일 접근 권한은 별도로 보호해야 합니다.

외부 API는 **공개 자료·일반 질문만** 사용하세요. 질문마다 **외부 전송·요금 확인**을 체크해야 전송합니다. 학생 정보·조퇴 사유·비공개 공문·쪽지를 붙여넣으면 안 됩니다. 명단 이름·연락처·수신자료 일부 일치 여부를 보조 검사하지만, 모든 민감정보를 찾아낼 수는 없습니다. 원문 업로드·자료 검색 연결은 제공하지 않습니다.

질문은 선택한 회사로 전송되며 제공사의 보관 정책과 별도 API 요금이 적용됩니다. ChatGPT·Claude의 월 구독과 API 요금은 별개일 수 있습니다. 제공사 콘솔에서 사용 한도·예산을 설정하세요. OpenAI에는 `store: false`를 요청하지만 제공사의 모든 보관을 막는다는 뜻은 아닙니다. 오류 시 비용 중복을 피하려고 자동 재시도하지 않으며, 다른 제공사로 자동 전환하지 않습니다. 앱은 일반 질문·답변을 DB·로그에 저장하지 않지만 열린 화면과 텔레그램 대화에는 남을 수 있습니다.

텔레그램에서는 **`/ask 질문`**으로 저장된 일반 질문용 AI를 사용합니다. 외부 API는 전송 대상·비용 안내 뒤 **공개 질문 · 전송 동의** 단추를 눌러야 보내며, 확인은 10분·1회만 유효합니다. `취소`로 아직 보내지 않은 질문을 취소할 수 있습니다. 이미 전송한 요청은 취소되지 않습니다. 기존 **AI 검색**은 계속 로컬 업무자료 검색입니다.

참고: [Chrome Prompt API](https://developer.chrome.com/docs/ai/prompt-api), [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), [Claude Messages API](https://platform.claude.com/docs/en/api/messages/create), [Gemini API](https://ai.google.dev/api/generate-content).

**수집 알림 보는 법**: 새 쪽지·공문이 들어오면 `📥 새 자료 n건 (쿨메신저 · 에듀파인)` 아래에 마감이 있는 것부터 `번호. [출처] 제목 · 보낸 사람` 과 `⏰ 날짜 (D-n) · 무엇을` 이 나옵니다. 한꺼번에 많이 들어오면(10건 초과, 처음 연결 등) 한 줄 요약과 가까운 마감만 나옵니다. 항목 아래 **📅 n 일정 등록** 을 누르면 수신함에서 체크한 것처럼 달력에 들어갑니다.

**봇이 답이 없을 때**: 같은 봇을 쓰는 업무 데스크가 두 곳 이상 켜져 있으면(개발용 폴더·다른 PC 등) 서로 방해해 답이 늦거나 없습니다. 텔레그램 `상태` 나 ⚙ 설정의 텔레그램 상태에 '같은 봇을 다른 곳에서도 쓰는 중 (409)' 가 보이면 한 곳만 남기세요 (개발용 폴더에는 토큰을 넣지 않습니다).

## 4-1. 내 시간표·수업 교체 (선택)

**시간표** 메뉴에서 학교 시간표 엑셀(.xlsx, 교사마다 몇 줄 · 요일 아래 교시 번호)을 불러오면:

- 설정의 담임 이름으로 **내 시간표**를 찾고 (다르면 직접 고름), 브리핑에 **오늘 내 수업**이 나옵니다.
- 바꿀 수업을 누르면 그 주 안에서 바꿀 수 있는 자리가 **초록 칸**으로 나옵니다: **맞교환**(그 학급 수업을 가진 선생님과 서로 바꿈), **2단계 교체**(그 선생님의 다른 수업까지 한 번 더). 배경색 칸·가로 병합 칸·고정 과목(자율·동아리·창체·봉사)은 바꾸지 않고, 연속 4교시 이상이 되는 선생님이 있으면 경고, 학사일정상 행사·휴업이 있는 날(그 학년)과 지난 날은 막습니다.
- 칸이나 후보를 누르면 바뀌는 선생님들의 하루 시간표 전·후, **교체 부탁 글**(쿨메신저에 붙여넣기)이 나옵니다. **교체 확정**을 누르면 그 주 시간표·오늘 내 수업·달력에 반영됩니다 (엑셀 파일은 고치지 않음).
- 시간표 아래 **교시 시간 · 수업 시작 알림**에 교시마다 시작·끝 시각을 넣으면 시간표·브리핑에 시각이 나오고, **수업 시작 알림**을 켜면 내 수업이 시작할 때(또는 5·10·15분 전) 텔레그램으로 "🔔 5분 뒤 3교시 (10:50~11:40) 2-1 국어 · 다음: …" 을 보냅니다 (교체 반영, 그 학년 행사·휴업 날은 안 보냄, 업무 데스크가 켜져 있어야 함).
- '나'는 설정의 담임 이름으로 정해지고, 다른 선생님 시간표를 볼 때 **[이 선생님을 '나'로]** 또는 아래 **'나' 바꾸기**로 바꿀 수 있습니다.
- 학교 전체 시간표를 고치고 바뀐 엑셀을 저장하거나 교체 안내문을 인쇄하려면 웹의 **[시간표 교체 도우미](https://aks-sci-lab.github.io/teacher-desk/timetable/)** 를 쓰세요 (설치 없이 브라우저만, 엑셀은 그 브라우저 안에서만 읽음).

## 5. 학생에게 조퇴증·외출증 공유하기

발급한 증 화면의 QR 을 학생 폰으로 찍게 하거나 링크를 보냅니다. 학생 폰에는 움직이는 시계와 줄무늬가 있는 증이 보입니다 (캡처한 화면과 구별).

- 증 내용은 **링크 주소의 `#` 뒤에만** 들어 있습니다. `#` 뒤는 서버로 전송되지 않으므로 공유 페이지(https://aks-sci-lab.github.io/teacher-desk/)에는 학생 정보가 저장되지 않습니다.
- 사유는 기본으로 링크에서 빠집니다 (링크가 다른 사람에게 전달될 수 있어서). 필요하면 작성할 때 "공유 링크에 사유 포함"을 체크합니다.
- 공식 기록은 인쇄한 증과 NEIS 입니다. 공유 링크는 편의용입니다.
- QR 을 그리는 도구는 인터넷(cdn.jsdelivr.net)에서 불러옵니다. 연결이 안 되면 링크 복사를 쓰세요.

## 6. 🧩 화면 배치 바꾸기

화면 오른쪽 아래 **🧩 화면 배치**를 누르면 영역마다 번호가 보입니다.

```
① 활동 막대  ② 목록 패널  ③ 탭 막대  ④ 작업 영역  ⑤ 하단 패널(기록)  ⑥ 상태 표시줄
```

- 목록 패널 위치(왼쪽/오른쪽), 하단 패널 보이기, 글자 크기(80~150%), 간격, 색상(밝게/어둡게)을 바로 바꿀 수 있습니다.
- 활동 막대 메뉴 이름을 바꾸고, 화면 배치 모드에서 왼쪽 메뉴를 끌어 같은 묶음 안의 순서를 바꿀 수 있습니다. 메뉴 이름을 비우면 원래 이름으로 돌아옵니다.
- **처음대로**를 누르면 메뉴 이름·순서와 화면 배치를 모두 기본값으로 되돌립니다.
- 경계선을 마우스로 끌어 너비·높이를 조절합니다.
- **📋 배치 설명 복사**를 누르면 지금 배치가 글로 복사됩니다. Claude Code 에게 붙여넣고 "④ 작업 영역의 오늘 카드를 2줄로" 처럼 번호로 바라는 점을 적으면 정확하게 고칠 수 있습니다.

## 8. 보안 설계

- 서버는 `127.0.0.1` 에만 열려 있어 **다른 컴퓨터·폰에서 접속할 수 없습니다.**
- 다른 웹사이트가 몰래 업무 데스크를 부르지 못하게 토큰·Host·Origin 을 확인합니다.
- 공문·메시지 분석은 AI 없이 규칙으로 하므로 **내용이 PC 밖으로 나가지 않습니다.** (텔레그램 알림만 예외이며 위의 설정으로 줄일 수 있습니다)
- 브라우저 단축키 연결(`/capture`)은 설정에서 켤 때만 열리고, 연결 키·확장 프로그램 origin·Host 를 모두 확인합니다. 다른 웹사이트는 키를 알아도 거절됩니다.
- 브리핑의 AI 요약은 **이 PC 에서 도는 LM Studio** 로만 보냅니다. 주소는 `127.0.0.1`·`localhost` 만 허용하고, 학생 명단의 이름은 `○○○` 로 가려서 보냅니다. 인터넷 AI(ChatGPT·Claude 등)로 보내는 기능은 없습니다.

## 9. 개발자용

```
python desk.py                  # 켜기
python desk.py --no-browser     # 브라우저 없이
python desk.py --collect        # 한 번 수집하고 끝
python desk.py --diagnose cool  # 쿨메신저 폴더 진단 → data/diagnose-cool.json
python -m unittest discover -s tests -t .   # 시험 (저장소 맨 위에서)
node --test tests/pass-codec.test.cjs       # 학생 공유 링크 시험
python tools/build_portable.py              # 윈도우용 ZIP 만들기 (dist/)
```

- 윈도우용 ZIP 은 `.github/workflows/desk-portable.yml` 이 윈도우에서 만들고 시험(들어 있는 Python 으로 시험 전체, 화면 열림, 바로 가기, 업데이트)한 뒤, `main` 에 반영되면 Releases 의 `desk-latest` 에 올립니다.
- 학생 공유 페이지(`pass/`)는 `.github/workflows/pages.yml` 이 GitHub Pages(https://aks-sci-lab.github.io/teacher-desk/)에 올립니다.

- `.bat` 파일은 한국어 윈도우 명령 창에서 한글이 깨지지 않게 CP949 로 저장합니다 (`.gitattributes`).
